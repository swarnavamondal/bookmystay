🏨 Hotel Booking Management System
App-Based Learning Using Core Java & Data Structures
📌 Overview

The Hotel Booking Management System is a console-based application designed to demonstrate how Core Java and fundamental data structures can be applied to solve real-world software engineering problems.

This project bridges the gap between theoretical concepts and practical implementation by showcasing how data structures power essential system behaviors like booking management, request handling, and inventory control.

🎯 Objective

The goal of this project is to:

Apply Core Java concepts in a real-world scenario
Demonstrate the practical use of data structures
Build a scalable and maintainable system design
Understand why and when specific data structures are used
🧠 Key Concepts Demonstrated
🔄 FIFO-Based Request Handling
Ensures fairness in booking requests
Implemented using Queue (FIFO principle)
🏨 Real-Time Room Inventory Management
Maintains consistent room availability
Prevents overbooking issues
🔐 Double Booking Prevention
Enforces uniqueness using appropriate structures like:
HashSet / HashMap
🧩 Extensible Architecture
Designed using Object-Oriented Principles
Easily adaptable for future enhancements
📚 Learning Approach

This project follows an incremental learning model:

Each feature introduces a new concept
Previous concepts are continuously reinforced
Design evolves from basic → scalable architecture
At Each Stage:
✔ Why a data structure is chosen
✔ What real-world problem it solves
✔ Limitations before refactoring
🛠️ Technologies Used
Java (Core Java)
Data Structures:

HashSet
📦 Features
Add and manage hotel rooms
Book rooms
